# Ships kernels for sm_50 through sm_90: Maxwell, Pascal, Volta, Turing, Ampere,
# Ada and Hopper. That covers GTX 900 series through RTX 40 series.
#
# It does NOT cover Blackwell, which is compute capability 12.0 and includes the
# RTX 50 series. A Blackwell card running this build fails every kernel launch
# with "no kernel image is available for execution on the device", which is not
# a driver problem and cannot be worked around at runtime. Those machines need
# requirements-train-cu128.txt, and setup picks between them automatically.
